# RiskTrail Backend

FastAPI backend that wires the ML fraud model and the RAG investigation
agent together behind one endpoint for the frontend to call.

## Run it

Run from the **repository root** (not from inside `backend/`), so that the
`ml/` and `rag/` packages import correctly:

```bash
uvicorn backend.main:app --reload --port 8000
```

Make sure before running:
- `ml/model.joblib` exists (already committed)
- `.env` at the repo root has `GROQ_API_KEY=...` set
- `pip install -r requirements.txt` has been run

Server will be available at: `http://localhost:8000`

Interactive API docs (auto-generated by FastAPI): `http://localhost:8000/docs`

## Endpoints

- `GET /` or `GET /health` — health check, returns `{"status": "ok"}`
- `POST /api/investigate` — main investigation endpoint

## Example requests

### Health check
```bash
curl http://localhost:8000/health
```

### Known transaction (fraud or legit — try any of TXN_001 to TXN_006)
```bash
curl -X POST http://localhost:8000/api/investigate \
  -H "Content-Type: application/json" \
  -d '{"transaction_id": "TXN_001"}'
```

Expected shape (real values will vary based on live ML + LLM output):
```json
{
  "transaction_id": "TXN_001",
  "risk_score": 87,
  "risk_level": "HIGH",
  "risk_factors": ["High transaction amount", "New device"],
  "evidence": [
    {"type": "case", "id": "CASE_014", "text": "..."},
    {"type": "policy", "id": "POLICY_001", "text": "..."}
  ],
  "investigation": "...",
  "recommendation": "..."
}
```

### Another known transaction (e.g. a legit one)
```bash
curl -X POST http://localhost:8000/api/investigate \
  -H "Content-Type: application/json" \
  -d '{"transaction_id": "TXN_004"}'
```

### Unknown transaction ID (404 path)
```bash
curl -X POST http://localhost:8000/api/investigate \
  -H "Content-Type: application/json" \
  -d '{"transaction_id": "TXN_999"}'
```
Expected:
```json
{"error": "Transaction not found", "transaction_id": "TXN_999"}
```
with HTTP status `404`.

### Malformed body (422 path)
```bash
curl -X POST http://localhost:8000/api/investigate \
  -H "Content-Type: application/json" \
  -d '{"wrong_field": "TXN_001"}'
```
FastAPI/Pydantic will return HTTP `422` automatically.
